- 위쪽 공개 소개 페이지는 1번 과제 그대로입니다. 그 안의 이름·이메일은 1번 과제에서 공개하기로 한 소개 내용이며, C11(1번 공개 내용 유지)에 따라 바꾸지 않았습니다. 비공개 영역에는 실제 개인정보가 없습니다.

## 확인 방법

1. **어디로 가나요**: 새 시크릿 창에서 https://skt-aleph-task8.vercel.app 를 엽니다. 가입·로그인은 필요 없습니다.
2. **세 단계 안에 무엇을 하나요**
   - ① 첫 화면이 소개 페이지인지 봅니다.
   - ② 메뉴의 「🔒 Private」을 눌러 맨 아래 비공개 영역으로 갑니다.
   - ③ 주소창에 https://skt-aleph-task8.vercel.app/api/private 를 직접 엽니다.
3. **무엇이 보이면 통과인가요**
   - 소개 내용이 그대로 보입니다.
   - 비공개 영역에는 "🔒 잠겨 있습니다. 패스키로 로그인하면 비공개 내용이 보입니다"와 「패스키로 로그인」 버튼만 있습니다.
   - ③의 주소는 `{"error":"패스키로 로그인해야 볼 수 있습니다"}`(401)를 돌려줍니다. 비공개 글은 페이지 소스 어디에도 없습니다.
4. **안 될 때는 무엇이 보이나요**
   - 로그인하지 않았는데 회고·메모 글이 보이거나, ③이 글 목록(200)을 돌려주면 차단이 실패한 것입니다.
   - 서버나 DB가 멈춘 경우에는 비공개 영역에 "서버에 연결하지 못했습니다" 또는 "비공개 내용을 불러오지 못했습니다"가 나옵니다.

## AI와 내 판단

   - 서버·화면·DB 코드 작성
   - 자동 테스트 58개와 콘솔 기록 도우미 작성
   - 확인 기록 정리, 설명서·제출문 초안 작성
2. **내가 직접 판단한 일**: 비공개 영역 위치와 세 종류, 가입 코드 방식, 마지막 패스키 삭제 불가와 다른 로그인 끊기, 아이폰 대신 Windows Hello, 실제 기기 등록·로그인·삭제 확인, 비밀값은 직접 입력
3. **AI 제안을 따르지 않은 일**: DB 역할 비밀번호를 16자 이상으로 하라는 제안을 따르지 않고 11자로 둠(설명서 ⑥-4에 위험을 적음)]`
